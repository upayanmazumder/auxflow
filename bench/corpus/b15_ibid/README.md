Two consecutive citations of one source sit near a page break under `biblatex`'s `authoryear-icomp` style, which shortens a citation to `ibid.` when the prior citation lands on the same page. `biblatex` is not in AuxFlow's modelled package set, so the document is OPAQUE under assumption A3 and AuxFlow refuses with `UNKNOWN`. Five real engine runs on this exact source settle by run 3 (page 2, full `Smith 2020, p. 2` form); a historical variant of this mechanism oscillates forever (tex.SE 81695, Paul Stanley's answer). The opaque-package rule must hold regardless of which case a given instance turns out to be, since AuxFlow cannot see inside `biblatex` to tell them apart.
