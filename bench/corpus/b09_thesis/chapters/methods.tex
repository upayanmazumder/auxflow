\chapter{Methods}\label{ch:methods}
This chapter defines the measurement procedure used at every site
described in Chapter~\ref{ch:intro}. The procedure follows the
classification method of an earlier study~\cite{smith2020}.

\section{Instruments}\label{sec:instruments}
Each site used the same instrument set: a fixed rule, a balance, and
a single recording sheet. The instrument set matches the auxiliary
record described in a later survey~\cite{doe2021}.

\section{Procedure}\label{sec:procedure}
The procedure records site, sample, source, condition, and date for
every item. Each record is checked against the shared reference
collection before it is logged.

\section{Recording}\label{sec:recording}
Every record uses the unit system defined in the background section
on page~\pageref{sec:background}.
